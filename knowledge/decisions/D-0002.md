# D-0002 — A creative tab and an EMI category for the table operations

Accepted 2026-09-22.

Rusty asked for the atlas to be exposed in a creative tab like the other mods, and for an EMI
recipe, before releasing.

The atlas was already in the vanilla Tools & Utilities tab. It now also has the mod's own
tab, "Magical Map", as Vanilla Wheels and Ranged Weapons Mod have theirs; the vanilla entry
stays so search and the usual tab keep working.

The atlas is not made by a crafting recipe: the cartography table's menu is extended by mixins,
so EMI has nothing to index. The three operations (map + book, atlas + map, atlas + shears) are
described once as data in the JDK-only domain (`AtlasRecipes`) and drawn by an EMI plugin under
a "Cartography Table" category with the cartography table as its workstation. The plugin class is
only loaded by EMI's entrypoint scan; EMI is an optional client-side dependency, compiled
against its API jar from the TerraformersMC maven and present at runtime only in the booth.
Version 1.1.24+1.21.1 is what the pack ships.

Verification: a GameTest rebuilds the tab contents and checks both tabs; the booth opens the
creative tab on the atlas and the EMI recipe screen for it, and photographs both.
